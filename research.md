<h2><span class="eyebrow">Work</span>Projects</h2>

<div class="card">
  <span class="card-meta">Literature Review</span>
  <h3>Review: Efficient Computations of Encodings for Quantum Error Correction</h3>
  <p>An analysis of methods to construct an efficient gate array that computes the code words for any stabilizer code with any set of generators, covering both standard and fault-tolerant encoding approaches with a focus on minimizing gate complexity while preserving error-correction capability.</p>
</div>

<div class="card">
  <span class="card-meta">Research Project &middot; Paper Communicated</span>
  <h3>Zeroing Neural Network Model for Finding Moore&ndash;Penrose Inverse of Time-Varying Tensors, with Applications in Imaging</h3>
  <p>Developed and implemented algorithms for computing the Moore&ndash;Penrose inverse of time-varying tensors under the M-product architecture, using zeroing neural networks (ZNN). Currently under review.</p>
</div>

<div class="card">
  <span class="card-meta">Computational Project</span>
  <h3>Analysis of Linear Convection-Dominated Singularly Perturbed Problems over Uniform and Non-Uniform Meshes</h3>
  <p>Designed and analyzed numerical methods for solving differential equations on non-uniform meshes, with a focus on improving stability and accuracy.</p>
</div>
